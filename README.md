## Aurevia – E-Commerce Website

Aurevia is a responsive women's e-commerce website developed using **React.js, Bootstrap, React Router, Context API, and JSON Server**. The project focuses on providing a modern and user-friendly shopping experience with product browsing, search, filtering, sorting, product details, wishlist, cart, checkout, and order confirmation features.

## Live Demo

🔗 **[Visit Aurevia – Live Website](https://aurevia-aura.vercel.app/)**

## Current Project Status

The current version of Aurevia includes the **complete frontend implementation** of the e-commerce website.

Product data is currently served using **JSON Server**, which acts as a mock backend for development and demonstration purposes.

### Implemented Features

* Responsive e-commerce UI
* Product listing and category-based browsing
* Product search
* Product filtering and sorting
* Dynamic product details
* Shopping cart
* Wishlist
* Checkout page
* Payment UI
* Order confirmation
* React Router navigation
* Context API for cart and wishlist state management
* LocalStorage for maintaining cart and wishlist data
* JSON Server for mock product data

## Future Development

Backend functionality is planned for future development, including:

* User registration and authentication
* MongoDB database integration
* Backend API development
* Order management
* User profile management
* Secure payment gateway integration
* Persistent cart and wishlist data
* Admin/product management

The current JSON Server implementation will be replaced with a proper backend and database as the project evolves.

## Tech Stack

* **Frontend:** React.js, JavaScript, HTML, CSS, Bootstrap
* **Routing:** React Router
* **State Management:** Context API
* **Mock Backend:** JSON Server
* **Data Storage:** LocalStorage
* **Deployment:** Vercel
* **Version Control:** Git & GitHub
